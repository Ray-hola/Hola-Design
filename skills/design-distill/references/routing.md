# Routing examples

- Learn a reference deck for future client reports: PPT. Inspect story, page types
  and viewing conditions; a few slides do not establish a whole narrative system.
- Learn an order console for returns: UI. Inspect objects, tasks and state changes;
  screenshots alone establish only visual observations.
- Adapt a site's expression to a new product website: web. Inspect purpose, section
  order, visual roles and responsive changes.
- Website plus authenticated workspace: web + UI. Share supported identity assets;
  keep section/content patterns separate from task/state patterns.
- Learn a brand manual: the manual is a source, not a scene. Infer the future task
  from context or clarify it. Shared colors/type do not establish absent patterns.
- Mixed reference images: classify by their role in the requested output and keep
  scene-specific evidence collections.

Minimal, technical, premium and dark are style/subject labels, not workflow routes.

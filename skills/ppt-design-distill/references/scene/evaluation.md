# Presentation transfer test

Use new content with a materially different information shape: e.g. a reference's
comparison page must also handle fewer options, a longer title or one missing
image. Keep the user's actual content; do not invent claims to fill a template.
Choose a short sequence that exercises the extracted pattern types. Do not force
a fixed slide count when fewer pages can establish the relevant behavior.

Give the consumer only the generated skill, requested content and permitted
assets. Note any extra source material it saw. A separate context/reviewer is
useful when available and authorized; an author's own pass is labeled as such.

Judge separately:
1. Source fidelity: measured/inferred rules and scope respected.
2. Message and sequence: claims clear, supporting evidence located, transitions
   coherent for the audience and presentation mode.
3. Page fit: titles, text, data and images fit without obscuring hierarchy.
4. Rendering/file correctness: inspect actual renders; for native PPTX, inspect
   text/chart editability and package validity with available tooling.
5. Transfer: the new content selected suitable patterns rather than copying a
   page and replacing text. Record a concrete mismatch or successful adaptation.

Render first, fix the most consequential defects together, then recheck changed
pages and relevant neighbors. Use the current creative protocol: change direction after repeated unchanged attempts; report unresolved issues honestly. Unavailable
native tooling means native-file check is skipped, not passed. HTML storyboard
or one preview is labeled as such, not a verified editable PowerPoint.


For the executable review record, follow [loop-protocol.md](../loop/loop-protocol.md).
New logs use adaptive exploration without default four/two repair quotas; explicit
user limits and legacy journal limits remain applicable. Use
[type-and-creative.md](../method/type-and-creative.md) for typeface and creative comparisons.
A convention departure is evaluated by purpose and overall relationships, not
marked failed merely for differing. Record unsupported/missing evidence honestly.
